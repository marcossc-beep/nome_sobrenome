// ### Antes de começar: o CRUD na tela

É o mesmo formato da pokedex: inputs com id, botões com onclick, uma div com id="lista" e fetch.

C - Create  = cadastrar  -> inputs + botão + fetch POST
R - Read    = listar     -> fetch GET + forEach montando a lista na tela
U - Update  = editar     -> botão editar preenche os inputs + fetch PUT
D - Delete  = excluir    -> botão excluir + fetch DELETE

Depois de CADA ação (cadastrar, editar, excluir) chamamos carregar() de novo, para a lista mostrar o que mudou.

Ferramentas que vamos usar:
  document.getElementById('lista')   pega o elemento que tem id="lista"
  .value                             lê (ou escreve) o que está dentro de um input
  .textContent                       escreve texto simples em um elemento
  .innerHTML                         escreve HTML dentro de um elemento (usado para montar a lista)
  array.forEach((item) => { ... })   repete um bloco para cada item do array que veio da API
  array.find((item) => condição)     acha o primeiro item que combina (usado no editar)
  `texto ${variavel}`                template literal: entre crases, ${} coloca uma variável no texto

Regra de ouro da lista: LIMPE antes (lista.innerHTML = '') e depois SOME com += dentro do forEach.
Se não limpar, cada recarga repete tudo.

Diferença para a pokedex: aqui usamos a função api() do scripts.js no lugar do fetch.
Ela é o mesmo fetch, só que já manda o token e trata a sessão vencida.

Escreva a função carregar() DENTRO do <script>, abaixo do let barbeiros = []:

// >>> FRONT/barbeiros.html
        async function carregar(busca) {
            const caminho = busca ? `/barbeiros?busca=${encodeURIComponent(busca)}` : '/barbeiros'
            barbeiros = await api(caminho)

            const lista = document.getElementById('lista')
            lista.innerHTML = ''

            barbeiros.forEach((barbeiro) => {
                lista.innerHTML += `
                <div class="item">
                    <b>${barbeiro.nome}</b> <br>
                    e-mail: ${barbeiro.email} <br>
                    telefone: ${barbeiro.telefone || ''} <br>
                    <button onclick="editar(${barbeiro.id})">editar</button>
                    <button onclick="excluir(${barbeiro.id})">excluir</button>
                </div>`
            })
        }
// <<<

E a chamada, que fica SEMPRE na última linha do script (acima do </script>):

// >>> FRONT/barbeiros.html
        carregar()
// <<<

// Como funciona:

// ### Passo 3: cadastrar (C)

Cole as duas funções ACIMA da linha carregar() do final.
A primeira só limpa os campos depois de cadastrar (querySelectorAll pega todos os inputs de dentro da div formulario).

// >>> FRONT/barbeiros.html
        function limparCampos() {
            document.querySelectorAll('#formulario input').forEach((input) => {
                input.value = ''
            })
        }

        async function cadastrar() {
            const barbeiro = {
                nome: document.getElementById('nome').value,
                email: document.getElementById('email').value,
                cpf: document.getElementById('cpf').value,
                senha: document.getElementById('senha').value,
                telefone: document.getElementById('telefone').value
            }

            const dados = await api('/barbeiros', 'POST', barbeiro)
            alert(dados.message)
            limparCampos()
            carregar()
        }
// <<<

// Como funciona:
// - Lemos cada input com .value e montamos um objeto barbeiro, igual ao pokemon da pokedex.
// - api('/barbeiros', 'POST', barbeiro) é o fetch com method POST e o objeto no body.
// - A API devolve { message: '...' } e mostramos essa mensagem com alert.
// - Depois limpamos os campos e chamamos carregar() para o novo barbeiro aparecer na lista.
//
// Teste: cadastre um barbeiro. Ele deve aparecer na lista.
// Critério 5.4: abra o pgAdmin e rode SELECT * FROM barbeiro; o cpf e a senha do novo barbeiro devem estar em hash
// ($2b$10$...). Se estiverem em texto puro, a criptografia da API (../backend/#3_criptografia_e_login.txt) não está aplicada.

// ### Passo 5: busca por termo

O usuário digita o termo, confirma (botão buscar) e a lista mostra só os registros que combinam.
O botão limpar busca volta para a lista completa. A parte da API (?busca= e ILIKE) está em ../backend/#1_busca_e_JOIN.txt.

// >>> FRONT/barbeiros.html
        function buscar() {
            carregar(document.getElementById('termo').value)

            document.getElementById('termo').value = ''
            carregar()

// - encodeURIComponent protege o termo na URL (espaços e acentos viram códigos seguros).
// - limparBusca() esvazia o campo e chama carregar() sem termo: lista tudo de novo.

// ### Passo 6: editar (U)

Como funciona, em ordem:
1. O usuário clica em editar no barbeiro.
2. editar(id) acha o barbeiro na lista (find) e joga os dados nos campos do formulário.
3. Guardamos o id num campo escondido, e trocamos o botão cadastrar pelo botão salvar alterações.
4. O usuário muda o que quiser e clica em salvar alterações (fetch PUT).
5. A lista recarrega e mostra o dado novo.

CPF e senha NÃO voltam preenchidos: estão em hash e não dá para mostrar. Só são trocados se o usuário digitar de novo.

No HTML, o campo escondido que guarda o id vai logo ABAIXO da div formulario e ACIMA do botão cadastrar:

// >>> FRONT/barbeiros.html
    <input type="hidden" id="id">
// <<<

E os dois botões novos, logo ABAIXO do botão cadastrar:

// >>> FRONT/barbeiros.html
    <button onclick="salvarEdicao()" id="botaoEditar" style="display: none">salvar alterações</button>
    <button onclick="limpar()">cancelar</button>
// <<<

No script, cole ACIMA da linha carregar() do final:

// >>> FRONT/barbeiros.html
        function editar(id) {
            const barbeiro = barbeiros.find((b) => b.id === id)

            document.getElementById('id').value = barbeiro.id
            document.getElementById('nome').value = barbeiro.nome
            document.getElementById('email').value = barbeiro.email
            document.getElementById('telefone').value = barbeiro.telefone || ''
            // cpf e senha estão em hash: só preenche se quiser trocar
            document.getElementById('cpf').value = ''
            document.getElementById('senha').value = ''
            document.getElementById('cpf').placeholder = 'novo cpf (opcional)'
            document.getElementById('senha').placeholder = 'nova senha (opcional)'

            document.getElementById('titulo').textContent = 'Editar barbeiro'
            document.getElementById('botaoCadastrar').style.display = 'none'
            document.getElementById('botaoEditar').style.display = 'inline'
        }

        async function salvarEdicao() {
            const id = document.getElementById('id').value
            const barbeiro = {
                nome: document.getElementById('nome').value,
                email: document.getElementById('email').value,
                cpf: document.getElementById('cpf').value,
                senha: document.getElementById('senha').value,
                telefone: document.getElementById('telefone').value
            }

            const dados = await api(`/barbeiros/${id}`, 'PUT', barbeiro)
            alert(dados.message)
            limpar()
            carregar()
        }

        function limpar() {
            limparCampos()
            document.getElementById('id').value = ''
            document.getElementById('cpf').placeholder = 'cpf'
            document.getElementById('senha').placeholder = 'senha'
            document.getElementById('titulo').textContent = 'Cadastrar barbeiro'
            document.getElementById('botaoCadastrar').style.display = 'inline'
            document.getElementById('botaoEditar').style.display = 'none'
        }
// <<<

// - barbeiros.find((b) => b.id === id) acha na lista o barbeiro que tem o id clicado.
// - salvarEdicao() é igual ao cadastrar(), mas com PUT e o id na rota: /barbeiros/ + id.
// - limpar() deixa a tela como no começo (também é o botão cancelar).
// - style.display = 'none' esconde o botão e 'inline' mostra.
//
// Teste: clique em editar, mude o nome, clique em salvar alterações. O nome novo aparece na lista e no banco.
// Teste: edite sem digitar CPF e senha; eles continuam como estavam.

// ### Erros comuns

- A lista repete os itens a cada ação: faltou lista.innerHTML = '' antes do forEach.
- Aparece "undefined" na lista: o nome do campo está diferente do que a API devolve (confira o JSON no Network, F12).
- "editar is not defined" ou "excluir is not defined": a função ainda não foi colada, ou foi colada fora do <script>.
- O editar não preenche nada: a função usa a lista "barbeiros", que só é preenchida dentro do carregar().
- Editar e excluir falham só no navegador: faltou PUT e DELETE em methods no CORS do server.js.
- O HTML montado em string precisa estar entre crases ( ` ), não entre aspas.
- Editou o barbeiro e o CPF mudou "sozinho": algum texto ficou digitado no campo cpf. Deixe vazio para manter o atual.
- Clicar em cadastrar não faz nada: confira o F12 > Console; quase sempre é erro de digitação no nome da função.
